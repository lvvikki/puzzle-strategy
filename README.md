# Puzzle Strategy

Webová stránka koučinku a konzultací — **Viktor Zemene**.

Jedna statická HTML stránka (`index.html`), bez závislostí a bez build kroku. Objednání sezení funguje přes předvyplněnou událost do Google Kalendáře / Outlooku (žádný server, žádná registrace).

## Spuštění lokálně

Stačí otevřít `index.html` v prohlížeči.

## Hosting zdarma přes GitHub Pages

1. **Settings → Pages**
2. *Source:* `Deploy from a branch`
3. *Branch:* `main` / `/ (root)` → **Save**

Web pak poběží na `https://lvvikki.github.io/puzzle-strategy/`.

## Úpravy

- Kontaktní e-mail je v `index.html` v konstantě `CONTACT_EMAIL`.
- Texty, služby a ceny jsou přímo v `index.html`.
